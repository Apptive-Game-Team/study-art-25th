# ArtUnityWorkshop
- 유니티 버전: 6000.6.2f1

`Assets/Scenes/Town.unity`를 열고 Play합니다. A/D 이동, Space 상호작용입니다. 게임 상태는 실행 중에만 유지됩니다.


### 1주차: Unity와 2D 캐릭터

- Unity
    - Scene, Game, Hierarchy, GameObject, Component(트랜스폼, 스프라이트 렌더러), Inspector
    - Sorting Layer, Order in Layer
    - prefabs
- 2D 캐릭터
    - Sprite Import 설정 : Sprite Mode, PPU, Filter Mode, Pivot
    - Sprite Editor
    - Animation Clip 과 Animator
- 실습: 스프라이트 시트 slice, Animation Clip교체

### 2주차: Canvas와 Particle System

- Canvas: UI옵션들 설명
    - UI 표시 순서
    - Rect Transform(Anchor,Pivot), TextMeshPro
    - Image: sprite 연결, 9-Slicing
    - Button: 상태, 트랜지션
- Particle System
    - Sprite Mode, Filter Mode, 투명도
    - 주요 옵션 & 옵션 별 예제
- 실습: UI변경, 파티클로 피격연출 변경

### 3주차: 타일맵과 3D 에셋

- 타일맵
    - Grid, Tilemap, Tile Palette
    - 타일셋 Import Settings, Tile Palette 도구
    - Tilemap 레이어 분리: Ground, Wall, Decoration, Foreground 분리
- 3D에셋
    - .blend .fbx
    - Mesh, Material, Texture, Rig
    - Animator를 이용한 포즈 전환
- 실습: 맵 변경, 3D파일 임포트&적용
- Post-processing: 간략히 소개
